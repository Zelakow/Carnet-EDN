Générateur de QR code

Un QR code à votre image vers votre portfolio, Google Drive ou site — prêt à glisser dans votre CV.

1. Le lien

Collez le lien de partage de votre portfolio.

Rendre un dossier Google Drive accessible
  1. Clic droit sur le dossier ou fichier → Partager.
  2. Dans « Accès général », choisissez Tous les utilisateurs disposant du lien (rôle : Lecteur).
  3. Cliquez sur Copier le lien et collez-le ci-dessus.
  4. Testez le QR code avec votre téléphone, en navigation privée, avant d'imprimer le CV.
